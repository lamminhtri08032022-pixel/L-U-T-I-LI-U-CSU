LƯU TÀI LIỆU CSU - ANDROID

Project Android native. Dữ liệu thiết bị dùng SQLite; ảnh/video/tài liệu được copy vào vùng lưu trữ riêng của ứng dụng trên điện thoại.

TẠO APK TRÊN WINDOWS:
1. Cài Android Studio nếu máy chưa có.
2. Trong Android Studio > SDK Manager, cài Android SDK Platform 35 và Build Tools 35.0.0.
3. Giải nén thư mục này.
4. Chạy TAO_APK.bat.
5. Khi hoàn tất sẽ có LUU_TAI_LIEU_CSU.apk trong cùng thư mục.
6. Chép APK sang điện thoại Android và cài đặt.

Không cần server/cloud. App không yêu cầu quyền truy cập toàn bộ bộ nhớ; file được chọn qua trình chọn file của Android rồi copy vào vùng dữ liệu của app.
